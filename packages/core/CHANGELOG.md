# @ktlsr/assay-core

## 0.1.0

First published release.

Suite schema and validator, deterministic assertion engine, three-valued verdicts, Wilson-interval scoring, and pin-checked run comparison. Pure TypeScript: no file system, no network, no child processes.

Part of [Assay](https://github.com/ktlesr/assay), a CI test runner for Agent
Skills. The four packages share a version number: they are components of one
SDK and are only tested together.
